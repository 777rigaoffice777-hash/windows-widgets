# Виджеты для рабочего стола Windows

Два маленьких полупрозрачных виджета для Windows 10 и 11.

**Блокировка экрана.** Большая кнопка включает или выключает автоблокировку: через 5 минут простоя экран становится чёрным,
а потом Windows спрашивает пароль. Кнопки «1 ч», «7 ч», «24 ч» снимают блокировку на время, потом она включается сама. После перезагрузки компьютера блокировка всегда включается снова (это можно отключить в меню).
Время на кнопках можно поменять правой кнопкой мыши. В трее у часов есть значок-замок: зелёный — блокировка включена,
красный — выключена.

**Календарь недель.** Календарь с номерами недель (неделя начинается с понедельника).

У обоих: прозрачность регулируется ползунком внизу, виджет можно перетащить мышкой куда удобно,
правая кнопка мыши открывает меню.

## Установка

Права администратора не нужны.

1. Скачайте архив: **[windows-widgets.zip](https://github.com/777rigaoffice777-hash/windows-widgets/releases/latest/download/windows-widgets.zip)**.
2. Откройте папку «Загрузки», нажмите на архив правой кнопкой мыши → **«Извлечь все…»** → «Извлечь».
3. В открывшейся папке дважды щёлкните **install-widgets.cmd**.
   Если Windows спросит «Запустить этот файл?», нажмите **«Запустить»**.

Через несколько секунд оба виджета появятся на рабочем столе. Дальше они сами запускаются при входе в Windows.
Распакованную папку после установки можно удалить.

## Что делает установщик

Ничего не скачивает: всё нужное уже лежит в архиве.
1. Копирует [AutoHotkey](https://www.autohotkey.com/) 2.0.31 (официальный файл с GitHub AutoHotkey) в `%LOCALAPPDATA%\Programs\AutoHotkey\v2`,
   если его там ещё нет. На нём работают виджеты.
2. Ставит виджеты в `%LOCALAPPDATA%\Programs\<Имя>`, добавляет их в автозапуск (задача планировщика «при входе», она запускает
   виджет за пару секунд, и запасная запись в автозагрузке) и в «Параметры → Приложения». Настройки — `%APPDATA%\<Имя>\settings.ini`.
## Обновления

Каждый день после 8:00 виджет сам проверяет этот репозиторий. Если здесь версия новее, он скачивает её,
проверяет файл на ошибки, ставит и перезапускается. Кнопка блокировки показывает у часов «Обновлено до версии …».

## Удаление

Правой кнопкой мыши по виджету → «Удалить с компьютера…» или «Параметры → Приложения → Установленные приложения».
При удалении кнопки блокировки автоблокировка включается обратно.

## Файлы

| Файл | Что это |
|---|---|
| `LockToggle/LockToggle.ahk` | Блокировка экрана |
| `WeekCalendar/WeekCalendar.ahk` | Календарь недель |
| `release/install-widgets.cmd` | Установщик (лежит в архиве рядом с виджетами) |
| `release/build-release.ps1` | Собирает архив для релиза |

Параметры командной строки виджетов: `--install` (тихая установка), `--portable` (запуск без установки),
`--update-check` (проверить обновление сразу), `--uninstall`.
