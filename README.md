# Виджеты для рабочего стола Windows

Два маленьких полупрозрачных виджета для Windows 10 и 11.

**Блокировка экрана.** Большая кнопка включает или выключает автоблокировку: через 5 минут простоя экран становится чёрным,
а потом Windows спрашивает пароль. Кнопки «1 ч», «7 ч», «24 ч» снимают блокировку на время, потом она включается сама.
Время на кнопках можно поменять правой кнопкой мыши. В трее у часов есть значок-замок: зелёный — блокировка включена,
красный — выключена.

**Календарь недель.** Календарь с номерами недель (неделя начинается с понедельника).

У обоих: прозрачность регулируется ползунком внизу, виджет можно перетащить мышкой куда удобно,
правая кнопка мыши открывает меню.

## Установка

Права администратора не нужны.

**Способ 1.** Скачайте файл [install-widgets.cmd](https://github.com/777rigaoffice777-hash/windows-widgets/releases/latest/download/install-widgets.cmd)
и откройте его.
- Если браузер спросит, сохранить ли файл, выберите «Сохранить».
- Если Windows покажет окно «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
- Если появится вопрос «Запустить этот файл?», нажмите «Запустить».

**Способ 2** (если первый не получился). Нажмите **Win + R**, вставьте строку ниже и нажмите **Enter**:

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/777rigaoffice777-hash/windows-widgets/main/install.ps1 | iex"
```

Через полминуты оба виджета появятся на рабочем столе. Они сами запускаются при входе в Windows.

## Что делает установщик

1. Скачивает [AutoHotkey](https://www.autohotkey.com/) 2.0.31 с официального GitHub AutoHotkey и проверяет контрольную сумму.
   На нём работают виджеты. Если AutoHotkey уже стоит, этот шаг пропускается.
2. Скачивает два виджета из этого репозитория.
3. Ставит их в `%LOCALAPPDATA%\Programs\<Имя>`, добавляет в автозапуск (задача планировщика «при входе» и запись
   в автозагрузке) и в «Параметры → Приложения». Настройки хранятся в `%APPDATA%\<Имя>\settings.ini`.

## Обновления

Каждый день после 8:00 виджет сам проверяет этот репозиторий. Если здесь версия новее, он скачивает её,
проверяет файл на ошибки, ставит и перезапускается. Кнопка блокировки показывает у часов «Обновлено до версии …».

## Удаление

Правой кнопкой мыши по виджету → «Удалить с компьютера…» или «Параметры → Приложения → Установленные приложения».
При удалении кнопки блокировки автоблокировка включается обратно.

## Файлы

| Файл | Что это |
|---|---|
| `LockToggle/LockToggle.ahk` | Блокировка экрана |
| `WeekCalendar/WeekCalendar.ahk` | Календарь недель |
| `install.ps1` | Установщик |
| `install-widgets.cmd` | Запускает установщик двойным щелчком |

Параметры командной строки виджетов: `--install` (тихая установка), `--portable` (запуск без установки),
`--update-check` (проверить обновление сразу), `--uninstall`.
