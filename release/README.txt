Виджеты «Блокировка экрана» и «Календарь недель» для Windows 10/11

Как установить:
1. Откройте файл install-widgets.cmd (двойной щелчок).
2. Если Windows спросит «Запустить этот файл?» — нажмите «Запустить».
Через несколько секунд оба виджета появятся на рабочем столе и дальше будут
запускаться сами при входе в Windows. Обновления приходят сами раз в день.

Что внутри:
- AutoHotkey64.exe, license.txt — AutoHotkey 2.0.31 с официального сайта
  (github.com/AutoHotkey/AutoHotkey), на нём работают виджеты;
- LockToggle.ahk — «Блокировка экрана», WeekCalendar.ahk — «Календарь недель».

Исходники и описание: https://github.com/777rigaoffice777-hash/windows-widgets
